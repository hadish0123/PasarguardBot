# طراحی صفحه‌به‌صفحه پنل کاربر نماینده

## U-01 خانه
نقطه شروع کاربر: خرید، سرویس‌های من، کیف پول، پروفایل و پشتیبانی.

## U-02 انتخاب سرویس
نمایش Panelهای فعال و سپس پلن‌های قابل فروش.

## U-03 انتخاب پلن
نمایش حجم، مدت، قیمت، IP limit و توضیحات.

## U-04 خرید دلخواه
```text
Volume → Days → Price → Username → Confirm
```

Validation باید قبل از رفتن به state بعدی انجام شود.

## U-05 تأیید خرید
خلاصه کامل سفارش + تخفیف + مبلغ نهایی + دکمه پرداخت.

## U-06 نتیجه پرداخت
سه حالت:
- موفق
- در انتظار
- ناموفق

## U-07 سرویس‌های من
لیست سرویس‌ها با وضعیت و زمان/حجم باقی‌مانده.

## U-08 جزئیات سرویس
نام، وضعیت، expiry، traffic، IP limit و عملیات مجاز.

## U-09 کیف پول
موجودی، افزایش موجودی، تراکنش‌ها.

## U-10 پروفایل
اطلاعات حساب و تنظیمات کاربر.

## U-11 پشتیبانی
ساخت درخواست، نمایش پاسخ و ادامه گفتگو.

## U-12 Referral
لینک دعوت، آمار و پاداش.

## U-13 Trial
Eligibility → Confirm → Create → Result.

## قرارداد هر صفحه
هر صفحه باید Entry point، state، keyboard، callback، DB/service calls، خطا، empty state و مسیر برگشت مشخص داشته باشد.
