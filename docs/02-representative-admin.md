# Representative Admin Panel

این پنل هسته مدیریت هر فروشگاه/نماینده است.

## A-01 — داشبورد
نمایش:
- وضعیت پنل Pasarguard
- وضعیت فروش
- تعداد کاربران
- تعداد سرویس‌های فعال
- موجودی/درآمد نماینده در صورت فعال بودن
- خطاهای مهم Runtime

## A-02 — مدیریت پلن‌ها
### صفحه لیست پلن‌ها
- لیست پلن‌های Tenant
- وضعیت فعال/غیرفعال
- قیمت
- حجم
- مدت
- نوع پلن

### ساخت پلن
Wizard:
1. انتخاب Panel
2. انتخاب نوع پلن
3. حجم
4. تعداد روز
5. قیمت
6. IP limit
7. محدودیت/نوع ترافیک
8. تنظیمات تکمیلی
9. تأیید و ذخیره

### ویرایش پلن
- تغییر قیمت
- تغییر مدت/حجم در محدوده امن
- فعال/غیرفعال
- حذف با confirmation
