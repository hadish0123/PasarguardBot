## Completion rule
یک feature زمانی کامل محسوب می‌شود که:
- UI/keyboard داشته باشد.
- handler داشته باشد.
- permission داشته باشد.
- state transition داشته باشد.
- DB/service integration داشته باشد.
- success/error/empty states داشته باشد.
- در Representative Runtime تست شده باشد.
