## U-02 — خرید سرویس
Flow:
1. انتخاب Panel/Service
2. انتخاب پلن
3. انتخاب حجم/مدت در خرید دلخواه
4. اعمال تخفیف
5. تعیین username/config name
6. مشاهده مشخصات نهایی
7. پرداخت
8. ساخت سرویس
9. نمایش نتیجه و اطلاعات اتصال
